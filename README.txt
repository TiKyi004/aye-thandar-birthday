# Aye Thandar Linn - Birthday Surprise Website

## Run in PyCharm
1. Extract this ZIP file.
2. Open the `aye_thandar_birthday` folder in PyCharm.
3. Right-click `index.html` and choose **Open in Browser**.
   - Or open `index.html` directly in Chrome.
4. No Python, Flask, database, or npm installation is required.

## Add your couple photos
Copy your own photos into `assets/photos/` and name them exactly:
- `photo1.jpg`
- `photo2.jpg`
- `photo3.jpg`

Use JPG images. You can add more photo cards by copying a `<figure class="photo-card">...</figure>` block in `index.html`.

## Add soft background music
Place a music file you have permission to use at:
`assets/music/soft-piano.mp3`

The music starts only after the visitor taps the Music button because browsers block autoplay with sound.

## Customize the birthday message
Open `index.html` and edit the text inside the `letter-text` paragraph and signature if you want a more personal message.

## Publish and share the link
You can publish the folder with GitHub Pages:
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. In repository Settings -> Pages, choose deploy from the `main` branch and root folder.
4. Wait for the published URL, then send that URL to her.

Keep personal photos private if you do not want them publicly accessible. Anyone with the public website link may be able to view them.
